# Diseño UX/UI - Landing Page Transportes Zamora

## Objetivo del sitio
Crear una landing page elegante, corporativa y premium para Transportes Zamora, empresa ubicada en Santa Cruz, Guanacaste, dedicada al transporte turístico, empresarial, institucional y privado.

## Estilo visual
- Diseño limpio y profesional.
- Fondo principal blanco.
- Azul marino como color principal.
- Azul medio como color secundario.
- Dorado como color de acento.
- Mucho espacio en blanco.
- Fotografías grandes y de buena calidad.
- Animaciones suaves y elegantes.

## Público objetivo
- Turistas nacionales e internacionales.
- Empresas.
- Instituciones educativas.
- Familias.
- Grupos organizados.
- Clientes que buscan transporte seguro y puntual.
