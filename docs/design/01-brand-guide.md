# Guia de marca

## Identidad visual

Transportes Zamora debe proyectar una imagen elegante, corporativa y premium. La experiencia visual debe transmitir solidez, orden y profesionalismo para clientes que buscan transporte turistico, empresarial, institucional o privado.

## Colores oficiales

- Blanco: `#FFFFFF`
- Azul Marino: `#0F3D66`
- Azul Medio: `#1F6FB2`
- Dorado: `#D9A321`
- Gris Claro: `#F5F7FA`
- Gris Oscuro: `#555555`
- Negro Suave: `#222222`

## Tipografias sugeridas

- Titulos: Poppins
- Texto: Inter

## Tono visual

El tono visual debe comunicar seguridad, puntualidad, comodidad y confianza. La composicion debe ser limpia, con buen uso del espacio, jerarquia clara y acentos dorados moderados para reforzar una sensacion premium.
