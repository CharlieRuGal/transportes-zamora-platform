# Organizacion de imagenes

Las imagenes deben organizarse por contexto de uso para mantener el proyecto claro y escalable.

## Rutas sugeridas

- `frontend/src/assets/images/hero`
- `frontend/src/assets/images/fleet`
- `frontend/src/assets/images/destinations`
- `frontend/src/assets/images/gallery`

## Lineamientos

Las imagenes deben mostrar unidades reales, destinos, detalles de comodidad y momentos de servicio. Se recomienda optimizarlas para web y mantener nombres descriptivos.
