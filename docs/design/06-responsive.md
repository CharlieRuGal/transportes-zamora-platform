# Comportamiento responsive

La landing debe adaptarse a escritorio, tablet y movil manteniendo claridad, jerarquia visual y facilidad de contacto.

## Escritorio

Las secciones principales pueden usar distribuciones en dos columnas, especialmente Hero, Sobre Nosotros, Servicios destacados y Contacto.

## Tablet

El contenido debe ajustar espaciados, tamanos de texto y separacion entre bloques. Las columnas pueden conservarse cuando haya espacio suficiente o pasar a una estructura mas compacta.

## Movil

El contenido debe mostrarse en una sola columna. Los botones deben ser faciles de tocar, las imagenes deben ocupar el ancho disponible y la navegacion debe simplificarse.
