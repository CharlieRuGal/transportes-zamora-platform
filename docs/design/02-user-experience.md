# Experiencia de usuario

## Usuario principal

Clientes que buscan servicios de transporte turistico, empresarial, institucional o privado en Guanacaste y zonas relacionadas.

## Objetivo principal

El objetivo del sitio es guiar al usuario a solicitar una cotizacion o contactar directamente a Transportes Zamora.

## Flujo esperado

1. El usuario entra al sitio.
2. Entiende rapidamente el servicio y la propuesta de valor.
3. Revisa elementos de confianza como seguridad, puntualidad, comodidad, historia, valores y testimonios.
4. Explora flota, destinos y servicios disponibles.
5. Contacta a la empresa o solicita una cotizacion.
