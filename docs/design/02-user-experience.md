# Experiencia de usuario

## Usuario principal

Clientes que buscan servicios de transporte turístico, empresarial, institucional o privado en Guanacaste y zonas relacionadas.

## Objetivo principal

El objetivo del sitio es guiar al usuario a solicitar una cotización o contactar directamente a Transportes Zamora.

## Flujo esperado

1. El usuario entra al sitio.
2. Entiende rápidamente el servicio y la propuesta de valor.
3. Revisa elementos de confianza como servicios destacados, estadísticas de impacto, resumen institucional y testimonios.
4. Explora flota, destinos y galería.
5. Resuelve dudas frecuentes.
6. Contacta a la empresa o solicita una cotización.

## Enfoque de contenido

La landing debe mantenerse clara y ligera. La sección Sobre Nosotros resume la información institucional principal, mientras que Historia, Misión, Visión y Valores quedan reservados para una futura página interna "Nosotros".

La sección "¿Por qué elegirnos?" no se desarrollará como bloque independiente para evitar una página demasiado extensa. Las ventajas competitivas deben aparecer de forma breve dentro de Sobre Nosotros, Impact Stats o Contacto.
